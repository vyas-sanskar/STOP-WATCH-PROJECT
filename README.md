# Stopwatch-PrecisionTimer

A simple and minimal stopwatch web application built using **HTML, CSS, and JavaScript**. The project focuses on JavaScript DOM manipulation to make the stopwatch interactive and functional.

### Features
- **Start:** Starts the stopwatch and tracks elapsed time.
- **Stop:** Pauses the stopwatch without resetting the time.
- **Restart:** Resets the stopwatch back to zero.
- Displays time in hours, minutes, seconds, and milliseconds.
- Modern, minimal, and responsive user interface.

### Technologies Used
- **HTML5** – Structured the stopwatch layout.
- **CSS3** – Designed the interface with a modern dark theme.
- **JavaScript** – Implemented stopwatch functionality and user interactions.

### Concepts Practiced
- DOM Manipulation
- Selecting HTML elements using `querySelector()`
- Event Handling `addEventListener()`
- Dynamically updating HTML content `textContent`
- JavaScript timing functions `setInterval() and clearInterval())`
- Variables and conditional logic

### Purpose
Built as a hands-on project while learning JavaScript DOM manipulation. It helped me understand how JavaScript interacts with HTML elements, handles user interactions, and dynamically updates webpage content.
